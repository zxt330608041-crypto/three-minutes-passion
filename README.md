# 三分钟热度 · Astro V1.1

**三分钟热度，也有三分钟的收获。**

一个关于好奇、尝试与热爱的兴趣指南。延续 V1.0 的兴趣分类、目录搜索筛选、详情、深度指南、随机发现和投稿草稿功能。

## 本地启动

```bash
npm install
npm run dev
```

打开 http://localhost:4321/ 。正式打包验证使用 `npm run build`。

## 内容管理

编辑 `src/content/hobbies/*.md` 即可维护兴趣，`src/styles/global.css` 包含温暖杂志风配色，`src/pages/index.astro` 是首页。

## 投稿说明

投稿页仅在浏览器中生成可复制/导出的草稿；没有用户账号、文件上传或后端收件功能，请勿将其误认作已在线提交。

## 部署

保留原版 GitHub Pages 工作流及 Astro 配置。设置 GitHub 仓库 Pages 来源为 GitHub Actions，并按仓库名称配置对应 base path。

## 其他

部分图片来自 Unsplash 外链，需联网加载；示例预算及教程搜索资源应持续核实。

页眉采用定制小火花 SVG + 中文字标，favicon 同步更新。其他功能和兴趣内容保持不变。
